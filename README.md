# examhigh

고등 수학 자료를 기본 틀(hwpx 양식)에 맞춰 새로 정리하는 저장소.

| 폴더 | 내용 |
|---|---|
| `기본틀/` | 정리 양식이 되는 hwpx 파일 |
| `원본/` | 정리할 대상 파일 |
| `결과물/` | 기본 틀 형식으로 정리한 완성본 |
| `양식안내.md` | 기본 틀의 페이지 설정과 블록 구성 설명 |
| `도구/` | 정리용 스크립트 (`content.py`에 내용, `build.py`가 기본 틀 블록으로 조립) |

## 작업 기록

- 원본 `기하_개념정리_2018.hwpx` 1~3쪽(Ⅰ. 이차곡선 – 1. 포물선) → `결과물/기하_개념총정리_이차곡선_포물선_1-3쪽.hwpx`
- 중간고사 범위: 원본 1~18쪽(Ⅰ. 이차곡선 전체 + Ⅲ. 공간도형 – 1. 공간도형의 위치 관계) → `결과물/기하_중간고사범위_개념총정리.hwpx` (`도구/content_mid.py`)
