# 시험지 분석 보고서 작성 방법

시험지(PDF·사진)를 올리면 Claude가 문항을 읽고 분석 데이터(JSON)를 채운 다음 아래 명령으로 **2쪽 보고서 PDF**를 만든다.

```
python 도구/exam_report.py 시험지분석/<학교>_<연도>_<학년-학기>_<시험>_<과목>.json
```

→ 같은 폴더에 `…_분석보고서.pdf` 생성 (필요 패키지: `pip install reportlab`)

## 고정 양식 (항상 2쪽)

| 쪽 | 절 |
|---|---|
| 1쪽 | 머리(AD FONTES 로고·시험명) · 기본 정보 표 · 1 출제 개요 요약 · 2 단원별 출제 비중 · 3 행동영역별 구성 · 4 킬러·변별 문항 |
| 2쪽 | 5 내신 5등급제 예상 등급컷 · 6 필수 문형 · 7 난이도별 분포 · 8 종합 총평·로드맵 · 9 다음 시험 대비 전략 · 꼬리말 |

내용이 넘치면 글자 배율을 1.00 → 0.76까지 자동으로 줄여 2쪽에 맞춘다. 그래도 넘치면 문구를 줄이라고 알려 준다.

## JSON에서 사람이(Claude가) 판단해 적는 것

- `items`: 문항마다 번호(`"1"`~, 단답형은 `"단1"`~), 배점, 단원 번호, 행동영역(계산력/이해력/문제해결력), 난이도(하 / 중하 · 중 / 중상 · 상 · 최상), 한 줄 주제
- `unit_features`: 단원별 "출제 문항 및 특징" 문구 (`**굵게**` 가능)
- `killers`: 킬러·변별 문항의 핵심 아이디어와 예상 정답률
- `grade_cuts`, `grade_basis`: 등급컷과 1컷 학생이 맞힐 문항 목록(부분 득점은 비율)
- `must_types`, `summary`, `roadmap`, `next_exam`: 필수 문형·총평·로드맵·다음 시험 전략

## 코드가 자동 계산하는 것 (손으로 적지 않음)

- 선택형·단답형 문항 수와 배점, 단답형 배점 목록
- 단원별 문항수·배점·비중(%)과 최다 배점 단원
- 행동영역·난이도별 문항수·배점과 "해당 문항" 번호 목록 (`1~5, 8번, 단1, 단3` 형태)
- 킬러 문항 배점 합계, 1컷 합산 점수(`{basis}`), 로드맵의 `{pts:1-6}` 같은 구간 배점 합

그래서 문항 표만 맞으면 보고서 안의 숫자끼리 어긋나지 않는다. 배점 합계가 100이 아니면 경고를 띄운다.

## 작업 기록

- 영일고 2026 2학년 2학기 중간 미적분I → `영일고_2026_2-2_중간_미적분I.json` / `_분석보고서.pdf`
  - 기존 분석지와 대조: 단원·행동영역·난이도 배점 합계는 모두 일치
  - 고친 점: 1컷 학생 합산이 실제로는 80.1점(기존 표기 81점) → 1등급 80점 이상, 2등급 64~79점으로 맞춤
  - 단원별 특징에 빠져 있던 단1(미정계수)·단2(그래프 극한)·단3(연속 미정계수)를 추가
