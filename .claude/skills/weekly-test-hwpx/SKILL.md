# 주간테스트 한글 시험지화

학교 시험지를 학원 주간테스트 양식으로 옮긴다. 기준 결과물은 미적분1 작업의
`주간테스트 - 2026년 2학기 중간 미적분1 목동고`이고, 양식의 세부(글꼴·여백·블록 구조)는
`references/format.md`에 있다. 양식은 `assets/template.hwpx`(목동고 결과물에서 문제 내용만 지운 것)를
그대로 복제해서 쓰므로, 글꼴·머리말·꼬리말·표지를 따로 만들 필요가 없다.

## 입력

| 입력 | 쓰임 |
|---|---|
| 원본 PDF | 학교 시험지 스캔. 문구·그림·배점의 기준. 손글씨 풀이가 섞여 있을 수 있다 |
| 변형된 한글 기본 (.hwp) | PDF를 한글로 옮긴 1차본. 수식 스크립트와 한글이 잰 수식 크기를 여기서 가져온다 |
| 시험기간 + 링크 | 표지의 `출제범위`. 보통 "시험범위 노트" 아티팩트 링크 |

.hwp 는 읽기만 한다. 결과물은 .hwpx 로 만든다.

## 순서

1. **원본 보기** — `pdftoppm -r 110 -png 원본.pdf p`로 쪽 이미지를 만들어 전부 본다.
   손글씨(풀이·체크·동그라미)는 시험지 내용이 아니다.
2. **한글 기본 읽기** — `python3 -I scripts/hwp_extract.py 기본.hwp 기본.txt 수식크기.json`
   - `기본.txt`: 문단 텍스트(수식 자리는 ◆) + `[수식] 스크립트`
   - 1차본에는 손글씨가 글자로 옮겨진 잔재(예: 풀이 식, `4×5×3×2=120`), 오타(`2기`, `미분Ⅰ`),
     빠진 기호(`×`)가 있다. PDF와 한 문항씩 대조해서 바로잡는다.
3. **출제범위** — 링크가 claude.ai 아티팩트면 `Artifact` 도구 `action: "read"`로 읽는다.
   시험범위 노트는 `SCHOOLS` 배열에 학교별 `schedule`·`ranges`가 있고, 범위 키는 `"과목"` 또는
   `"2학년:미적분Ⅰ"` 꼴이다. 해당 과목 범위가 비어 있으면 문항을 보고 단원을 정리해 넣고
   (예: `함수의 극한 – 도함수`) 확인이 필요하다고 알린다.
4. **정답·해설** — 모든 문항을 직접 푼다. 학교 정답지는 없다. 숫자로 확인할 수 있는 것은
   python(sympy 등)으로 검산하고, 보기 중 정답이 하나로 정해지는지 확인한다.
   해설은 짧게: 핵심 식 몇 개와 `∴ 답`. 원본이 잘려 복원한 문항은 `note`에
   `※ 원본 사진에서 … 복원했습니다. 원본 확인 필요.`
5. **그림** — 원본을 잘라 쓰지 않고 다시 그린다. `scripts/exam_graph.py`의 `axes`·`save`로
   흑백 시험지 스타일(화살표 축, O, 점선 보조선, 열린/채운 점) PNG를 만든다. 그린 뒤 원본과 비교해 본다.
6. **내용 파일 작성** — 아래 형식으로 `content.py`를 쓴다. 예시는 `references/example_content.py`.
7. **조립** — `python3 scripts/build_weekly.py content.py 결과.hwpx --eqsz 수식크기.json`
   그다음 hwpx 스킬의 `validate.py`로 구조를 검사한다.
8. **빠른정답** — 만들지 않는다. 조립기가 문제를 짝수 쪽에서 끝내고 다음 홀수 쪽 왼쪽 단에
   커서 자리를 만들어 둔다. 사용자에게 한글에서 문서 끝에 커서를 두고
   **빠른정답컨트롤v2(Alt+Shift+2)** 를 누르라고 안내한다(hwp-exam-layout 스킬 규칙).
9. 결과물은 저장소 `결과물/`에 저장하고 commit·push 한 뒤 파일을 보낸다.

## 내용 파일 (content.py)

```python
TITLE = '주간테스트 - 2026년 2학기 중간 미적분1 ○○고'   # 표지 제목
RANGE = '함수의 극한 – 도함수'                           # 출제범위
TOTAL = 100                                              # 학교 만점 그대로 (목동고는 60)
MINUTES = 50                                             # 제한시간, 보통 50

ITEMS = [
    {   # 선택형
        'stem': ['함수 $f LEFT (x RIGHT )  =  …$에서 … 값은? [3.9점]',   # 첫 문단(문항 번호=미주 번호가 앞에 붙음)
                 ('d', '가운데 줄 수식 스크립트'),
                 ('box', '조건', ['(가) …', '(나) …']),                   # '보기' 또는 '' 도 가능
                 ('img', 'fig_q4.png', 53),                               # 가로 mm
                 '이어지는 문단 …'],
        'choices': ['$12$', '$13$', '$14$', '$15$', '$16$'],              # 짧은 수식이면 3+2 줄, 아니면 5줄
        'answer': '①',
        'sol': ['해설 문단', '…'],
        'note': None,               # 복원 메모(선택)
        'hard': False,              # 어려우면 True → 한 단에 1문항
    },
    {   # 서답형 — 첫 서답형 앞에 '※ 여기서 부터는 서답형 문제입니다.' 자동
        'title': '[서답형 1]',
        'stem': ['…다음 물음에 답하시오. [총 6.0점]'],
        'subs': ['(1) … [3.0점]', ('(2) … [3.0점]', 8)],               # (문단, 뒤 빈 줄 수), 기본 5
        'answer': '(1) $3$ (2) $5$',
        'sol': ['…'],
        'hard': True,               # 서답형은 기본 True
    },
]
```

- 수식은 `$…$` 안에 한글 수식 스크립트. 한글 기본 파일의 스크립트를 그대로 쓰면 `--eqsz`로
  크기가 맞는다. 새로 쓴 수식은 크기를 어림하고, 한글에서 열 때 다시 계산된다.
- 배점은 학교 원본 그대로 발문 끝에 `[4.2점]`.
- 배치: 쉬운 문항은 한 단에 2개(첫 문항 뒤 빈 줄 16개), 어려운 문항은 한 단에 1개.
  단 나누기만 쓰고 쪽 나누기는 쓰지 않는다. 어려움 판단은 배점·발문 길이·조건 상자 유무를 본다.

## 확인할 것

- 문항 수, 각 문항의 보기 5개, 배점 합계가 만점과 같은지
- 정답이 모두 검산됐는지, 미주 번호가 1부터 이어지는지(서답형도 이어짐)
- 한글로 열어 보는 것은 이 환경에서 못 하므로, 사용자에게 열어서 수식 간격·쪽 배치를 봐 달라고 한다

## 템플릿 다시 만들기

양식이 바뀌어 새 결과물을 기준으로 삼을 때:
`python3 scripts/make_template.py 새결과물.hwpx assets/template.hwpx 아무그림.png`
(견본 문단 위치가 목동고 결과물 기준이라, 구조가 다르면 스크립트의 `idx`를 고친다)
